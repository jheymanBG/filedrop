# FileDrop

Secure file transfer application for the City of Bowling Green.

## Current Features

- IIS hosting
- SQL Server backend
- Secure upload/download links
- Email notifications
- Download notifications
- Admin dashboard
- Audit log
- Reports
- Health checks
- Branding
- Backup/rollback tools
- Entra readiness
- Temporary local upload mode

## Notes

Do not commit production secrets, uploaded files, SQL backups, or appsettings.Production.json.
